# Vanna Farsi - نسخه فارسی وانا

نسخه فارسی وانا با قابلیت اجرای محلی بدون نیاز به API وانا

## ویژگی‌ها

- **پشتیبانی کامل از زبان فارسی**: رابط کاربری کاملاً به فارسی
- **اجرای محلی**: بدون نیاز به API خارجی
- **پشتیبانی از مدل‌های محلی**: استفاده از Ollama و مدل‌های محلی
- **رابط کاربری زیبا**: طراحی مدرن و کاربرپسند
- **پشتیبانی از پایگاه‌های داده مختلف**: PostgreSQL، MySQL، SQLite و غیره

## نصب

```bash
pip install -r requirements.txt
```

## راه‌اندازی

### 1. نصب Ollama (برای مدل‌های محلی)
```bash
# Ubuntu/Debian
curl -fsSL https://ollama.ai/install.sh | sh

# macOS
brew install ollama
```

### 2. دانلود مدل
```bash
ollama pull llama2
# یا
ollama pull mistral
```

### 3. اجرای برنامه
```bash
python app.py
```

## استفاده

1. برنامه را در مرورگر باز کنید: `http://localhost:5000`
2. سوال خود را به فارسی بپرسید
3. SQL تولید شده را مشاهده کنید
4. نتایج را در قالب جدول و نمودار ببینید

## مثال‌ها

- "۱۰ مشتری برتر بر اساس فروش را نشان بده"
- "میانگین سن کارمندان در هر بخش چقدر است؟"
- "فروش ماهانه سال گذشته را نمایش بده"

## پیکربندی

فایل `config.py` را برای تنظیمات پایگاه داده و مدل ویرایش کنید.
